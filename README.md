# shushant17711.github.io

Portfolio of Shushant Kumar Choudhary: ML research in quantum error correction, quantum ML, world-model control and AI-agent safety.

Live at **https://shushant17711.github.io/**

A single scroll-driven page. Static HTML, CSS and JavaScript with no build step: Three.js scenes (a gold-dust Bloch sphere, a surface-code lattice, a powered-descent lander, a drone swarm), GSAP ScrollTrigger and Lenis for the scroll. Every project image is a real figure or README table from the matching repo.

Run locally:

```sh
python3 -m http.server 8833
```
